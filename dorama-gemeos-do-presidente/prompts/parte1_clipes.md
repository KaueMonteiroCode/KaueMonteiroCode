# Parte 1 — "O Elevador" · 17 clipes

Cada clipe tem **2 passos**:

- **A. Quadro inicial (ChatGPT):** anexe as imagens indicadas, cole o prompt A e salve o resultado como `p1_cXX_quadro.png`.
- **B. Animação (Grok Imagine):** suba o quadro, cole o prompt B, gere e baixe como `p1_cXX.mp4`.

**Regras que valem pra todos:**

- Todos os quadros saem na **vertical 9:16**. Se o ChatGPT fizer quadrado, responda *"refaça na vertical 9:16"*.
- Se o rosto de alguém sair diferente da ficha, responda: *"O rosto de [nome] precisa ser idêntico à ficha anexada."*
- No Grok **não importa o áudio**: o editor usa só as vozes do Fish. Nos clipes com fala, a boca mexendo de leve já basta.
- A coluna **Duração** é quanto o clipe precisa ter **no mínimo**. Se sair mais curto, o editor congela o último quadro.
- Fichas: `seoyeon_ficha`, `dohyun_ficha`, `gemeos_ficha`. Cenários: `cenario_saguao`, `cenario_corredor_manha`, `cenario_elevador`.

Estilo (já incluído nos prompts A): *fotorrealista, visual de K-drama de alto orçamento, iluminação suave e brilhante, lente de cinema, profundidade de campo rasa.*
