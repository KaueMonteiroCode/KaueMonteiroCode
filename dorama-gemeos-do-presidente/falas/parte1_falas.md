# Parte 1 — "O Elevador" · Falas para gerar no Fish Audio

**Como gerar:**
1. Uma fala por vez (cole só o texto entre aspas, sem o nome do personagem).
2. Gere 2–3 vezes e baixe a versão com a emoção mais certa.
3. Salve com o **nome de arquivo exato** da tabela (é assim que o editor encaixa cada áudio).
4. Pontuação muda a interpretação: `...` = pausa/hesitação, `!` = mais força, `?` = entonação de pergunta. Não tire.
